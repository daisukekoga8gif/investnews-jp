# 著作権リスク管理・掲載ルール

## 基本方針

このサイトは「キュレーション型ニュースサービス」として設計されており、
記事本文の転載を一切行わず、元記事への誘導を目的としています。

---

## 掲載内容の制限

### 掲載するもの ✅
- 記事タイトル（元のまま）
- 出典名（サイト名）
- 元記事URL
- 公開日時
- **AIが独自に生成した要約**（元記事の丸写しではない）
- **AIが独自に生成した投資家向けポイント**（元記事の丸写しではない）

### 掲載しないもの ❌
- 記事本文の転載・抜粋（20文字以上の連続した原文）
- 有料記事・ログイン必須記事の本文
- 記事内の画像・図表
- 動画コンテンツ

---

## AI要約の生成ルール

Claude APIへのプロンプトに以下を明記：
1. 「記事本文を丸写ししない」
2. 「元記事への送客を前提にした短い要約を生成する」
3. 「投資助言にならない事実ベースの記述にする」

これにより、生成される要約は元記事とは独立した二次著作物として扱えます。

---

## robots.txt・利用規約の遵守

### 確認手順（新規ソース追加時）
1. `https://対象サイト/robots.txt` を確認
   - `Disallow: /rss` の場合はRSS取得不可
   - `User-agent: *` で制限がなければ取得可
2. 各サイトの利用規約を確認（「RSS利用可」記載があれば安全）
3. DBの `sources.robots_ok` を `true` に設定してから有効化

### 主要サイトのRSS利用状況（確認済み）
| サイト | RSS | 利用規約での言及 |
|--------|-----|-----------------|
| Reuters Japan | ✅ 公式RSS提供 | 個人利用可 |
| Bloomberg JP | △ 要確認 | 商用利用制限あり |
| 日本経済新聞 | ✅ 公式RSS | 個人・非商用のみ |
| Yahoo!ファイナンス | ✅ 公式RSS | 非商用利用可 |
| みんかぶ | ✅ RSS提供 | 要確認 |

**⚠️ 商用利用の場合は各サービスに個別確認を推奨**


## 免責事項の掲載

フッターに以下を必ず表示：
- 「このサイトは投資ニュースのキュレーションサービスです」
- 「記事の転載は行っておらず、元記事への誘導を目的としています」
- 「掲載情報は投資助言ではありません。投資は自己責任で行ってください」

---

## 問題発生時の対応手順

1. 権利者からクレームを受けた場合
   → 該当記事を即時非公開（`is_published = false`）
   → 除外ドメインに追加（`excluded_domains` テーブル）
   → 以後そのドメインからは取得しない

2. 誤った内容のAI要約が掲載された場合
   → 管理画面から即時修正または非公開

---

## 法的根拠

- 著作権法 第32条（引用）：目的上正当な範囲で引用可能
- ただし「引用」の要件（主従関係・明瞭区分性・出所明示）を満たすこと
- 本サービスは引用ではなく「独立した要約の生成」として設計
- 不明な場合は弁護士に確認することを推奨
